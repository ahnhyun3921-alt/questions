# 질문 태깅 기준 (analysis/question_tags.csv)

새 질문이 생기면 이 기준으로 한 줄씩 추가한다. `analyze_v2.py`는 태그가 없는 질문이 있으면 멈춘다.
열: `id,T,P,E,W,S,F,C`

| 코드 | 차원 | 값 |
|---|---|---|
| T | 시점 고정 | 0 없음 · 1 요즘/지금/최근 · 2 오늘/이번 주/내일처럼 특정 날에 묶임 |
| P | 경험 전제 | 0 누구나 답함 · 1 대부분 답함 · 2 특정 경험·상황(연애 중, 운동, 오늘 일어난 일 등)이 있어야 답함 |
| E | 인지 노력 | 1 즉답 · 2 잠깐 생각 · 3 깊은 성찰·추상 개념 |
| W | 감정 무게 | 1 가벼움 · 2 보통 · 3 무거움(상처, 죽음, 실패, 비밀) |
| S | 자기노출 | 1 낮음 · 2 보통 · 3 높음(약점·비밀·가족 갈등 고백) |
| F | 형식 | p 선호(최애) · t 성향·습관 · c 양자택일 · r 일화 회상 · h 상상·가정 · d 개념·가치 정의 · n 특정 인물 지목 · o 기타(예/아니오, 청유 등) |
| C | 명료성 | 0 명료 · 1 은유·모호('감정의 온도', '단골손님처럼') |

판단 예시
- "오늘 기억에 남는 소리나 향기가 있다면?" → T2 P2 E1 W1 S1 r C0
- "가장 좋아하는 날씨는?" → T0 P0 E1 W1 S1 p C0
- "나를 가장 힘들게 했던 인연은 누구였나요?" → T0 P2 E2 W3 S3 n C0
- "완전한 자유와 무조건적인 권력 중 뭐가 더 갖고 싶나요?" → T0 P0 E1 W1 S1 c C0
